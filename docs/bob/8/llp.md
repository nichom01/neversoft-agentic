# Low-level plan: #8 ui styling

## Overview
The approved high-level plan restyles the Bob pipeline dashboard (`tools/bob-pipeline/apps/web`, React + Vite + Tailwind CSS v4) to emulate the Chakra UI Pro look. It does this with a token layer, restyled shared primitives, a restyled shell and a class-name sweep. It is presentation only.

All paths below are relative to `tools/bob-pipeline/apps/web/` unless they start with `tools/`.

Design decisions, fixed here so the implementation stage does not re-decide them:

1. **Tokens (Tailwind v4 `@theme` in `src/index.css`).** Each `--color-*` token yields a utility class (`bg-brand-700`, `border-line`, `text-muted` and so on). The tokens are:
   - Font: `--font-sans: "Inter Variable", ui-sans-serif, system-ui, -apple-system, "Segoe UI", sans-serif`.
   - Brand (Tailwind teal values): `--color-brand-50 #f0fdfa`, `100 #ccfbf1`, `200 #99f6e4`, `300 #5eead4`, `400 #2dd4bf`, `500 #14b8a6`, `600 #0d9488`, `700 #0f766e`, `800 #115e59`, `900 #134e4a`.
     - Solid brand fills with white text use **700 or darker**. `brand-600` is 3.7:1 against white and fails AC-7.
   - Neutral semantic tokens: `--color-canvas #f9fafb` (page), `--color-surface #ffffff`, `--color-subtle #f3f4f6` (kanban column, hover fill), `--color-line #e5e7eb`, `--color-line-strong #d1d5db`, `--color-ink #111827`, `--color-muted #4b5563`.
     - `muted` is at least 4.5:1 on white, canvas and subtle. This replaces the old `slate-400/500` text, which fails on `slate-100`.
   - Console tokens (log view and JSON `<pre>`): `--color-code #111827`, `--color-code-bar #1f2937`, `--color-code-ink #e5e7eb`, `--color-code-muted #9ca3af`.
   - Radii: `--radius-control 0.375rem`, `--radius-card 0.5rem`.
   - Shadows: `--shadow-card: 0 1px 2px 0 rgb(0 0 0 / 0.05), 0 1px 3px 0 rgb(0 0 0 / 0.08)` and `--shadow-pop: 0 4px 6px -1px rgb(0 0 0 / 0.1), 0 2px 4px -2px rgb(0 0 0 / 0.1)`.
2. **Global base rules (`@layer base`).**
   - `body` gets `background: var(--color-canvas); color: var(--color-ink); font-family: var(--font-sans); -webkit-font-smoothing: antialiased`. These replace the classes on `<body>` in `index.html` and the old `:root` font-family.
   - A single focus rule gives every interactive element the same visible keyboard focus: `:where(a, button, input, textarea, select, summary):focus-visible { outline: 2px solid var(--color-brand-600); outline-offset: 2px; }`. Individual components must not use `outline-none`.
   - `.prose { --tw-prose-links: var(--color-brand-700); }` so markdown links follow the accent. The existing `.prose table` rule stays.
3. **Semantic colours stay semantic.** Success, danger, warning and diff add/remove colours (`emerald`, `red`, `amber`, `sky`) remain as meaning-bearing colours: status badges, the diff `+`/`-` lines, run-status dots and the warning banner. The brand teal replaces `emerald` on **primary actions, active states and surfaces** and `slate`/`indigo` ad-hoc chrome. Brand and success are therefore not conflated.
4. **Hex colours in TS (graph, pyramid)** cannot use Tailwind classes. Each file gets one small constant object of hex values that mirrors the tokens, with a comment pointing at `index.css`. No new shared module is added.
5. **No behaviour changes.** Only `className`, inline style colours, one `import`, and `index.html`/`index.css` change. No JSX structure, props, hooks or routes change. The only structural addition is the two wrapper-class tweaks noted below.
6. **Contrast (AC-7).** Every text/background pair introduced is at least 4.5:1:
   - white on `brand-700` is 5.5:1; white on `brand-800` is higher.
   - `brand-700` on `brand-50` is about 5.2:1.
   - `muted` on `subtle` is about 6.9:1.
   - Badge pairs stay at `*-100` background with `*-800` text.
   - `emerald-600` text on white (3.8:1) moves to `emerald-700`.
   - `red-600` text moves to `red-700`.
   - Log timestamps move from `slate-500` to `code-muted`.

## Rollout
Order, with a typecheck and a visual check after each step, to limit regression risk:
1. Add the dependency (`package.json`, lockfile), the `main.tsx` import, and the `index.css` tokens and base rules, and strip the `<body>` classes in `index.html`. The app should look nearly unchanged except for font and background.
2. `ui.tsx` primitives. Every page now inherits the Button, badge and Card look.
3. `Layout.tsx` shell.
4. `Dashboard.tsx`, then `IssuePage.tsx` with `LogView.tsx` and `views/base.tsx`, then `DependenciesPage.tsx` with `DependencyTable.tsx`, `DepGraph.tsx` and `views/DependencyView.tsx`, then `views/TestPyramidView.tsx`.
